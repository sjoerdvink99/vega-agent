# Examples

Each example uses only the public API. Find them in [`examples/`](https://github.com/sjoerdvink99/vega-agent/tree/main/examples).

| Example | Shows |
|---|---|
| [Trace explorer](https://github.com/sjoerdvink99/vega-agent/tree/main/examples/explorer) | a visual analytics tool in TypeScript: variants, a run's diagram and timeline, and transitions, linked by selection |
| [Plain web page](https://github.com/sjoerdvink99/vega-agent/blob/main/examples/web/index.html) | the library in one HTML file, with no build step |
| [Regression report](https://github.com/sjoerdvink99/vega-agent/tree/main/examples/node) | figures for two model versions in CI, failing when failures become more common |
| [Grammar](https://github.com/sjoerdvink99/vega-agent/blob/main/examples/notebooks/01_grammar.ipynb) | expressions, charts, sampling and abstraction in a notebook |
| [Traces](https://github.com/sjoerdvink99/vega-agent/blob/main/examples/notebooks/02_traces.ipynb) | OpenTelemetry and ATIF, queries, exploring a corpus |
| [Model upgrade](https://github.com/sjoerdvink99/vega-agent/blob/main/examples/notebooks/03_model_upgrade.ipynb) | did a new model break the harness? |
| [Failure triage](https://github.com/sjoerdvink99/vega-agent/blob/main/examples/notebooks/04_failure_triage.ipynb) | which steps fail, what happens next, which runs leave the harness |

The example data is synthetic, made by [`examples/data/generate.py`](https://github.com/sjoerdvink99/vega-agent/blob/main/examples/data/generate.py).
