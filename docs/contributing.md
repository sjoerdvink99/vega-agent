# Contributing

The project is open source under the MIT License, and contributions are welcome: bug reports, new telemetry readers, new marks, and docs.

- Read [CONTRIBUTING.md](https://github.com/sjoerdvink99/vega-agent/blob/main/CONTRIBUTING.md) for the set-up and the rules.
- Open an [issue](https://github.com/sjoerdvink99/vega-agent/issues) for bugs and ideas.
- Built something with it? Open a pull request that adds it to the [examples](examples/index.md).

The fastest contribution is often data, not code: a new telemetry dialect is a rule in `grammar/conventions.json` plus a real-shaped case in `grammar/standards.json`.

## Cite

If you use the library in research, cite it with [`CITATION.cff`](https://github.com/sjoerdvink99/vega-agent/blob/main/CITATION.cff).
